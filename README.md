# Employee Management System

## 📌 Project Overview
Employee Management System is a desktop-based application developed using **Java Swing** and **JDBC**. The application helps organizations efficiently manage employee records through an easy-to-use graphical user interface.

The system allows users to perform essential employee management operations such as adding, updating, deleting, and viewing employee details while maintaining smooth database connectivity.

---

## 🚀 Features

- ➕ Add new employee records
- ✏️ Update employee information
- ❌ Delete employee records
- 👀 View employee details
- 🔍 Search employees easily
- 💾 Database connectivity using JDBC
- 🖥️ User-friendly Java Swing interface
- 📊 Efficient employee data management

---

| Technology | Description |

| JDBC | Database connectivity |
